# СорбентОпт

Профессиональный SEO-ориентированный сайт для оптовых поставок глауконитовой продукции.

## Стек

- Astro 6 — быстрый статический фронтенд
- TypeScript для структуры данных
- Node.js + Express — API заявок
- SQLite — база заявок
- Caddy — HTTPS/reverse proxy

## Что уже сделано

- семантический HTML5;
- один H1 на страницу, логичная иерархия H2/H3;
- title, description, canonical;
- Open Graph и Twitter Card;
- robots.txt и sitemap через Astro;
- JSON-LD Organization/WebSite/Product;
- отдельный каталог и SEO-страницы каждого товара;
- alt-тексты изображений;
- адаптивная мобильная версия;
- доступная навигация и skip-link;
- форма заявки с серверной валидацией;
- SQLite для заявок;
- базовая защита API и rate limit;
- 404 и страница политики обработки данных;
- Caddyfile и systemd unit для VPS.

## Важно

Перед реальным запуском замените демонстрационные телефон, email, домен и цены на реальные данные. Страницу политики персональных данных также нужно заполнить фактическими реквизитами оператора.
